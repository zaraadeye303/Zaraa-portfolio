# AWS Cloud Project – Secure S3 Storage with IAM

## Overview
This project demonstrates how to set up a secure AWS S3 bucket and manage access using IAM (Identity and Access Management). It reflects my understanding of cloud security principles.

## Steps
1. Created an **S3 bucket** with versioning enabled for data durability.
2. Configured **bucket policies** to restrict public access.
3. Used **IAM roles and policies** to give fine-grained access to specific users.
4. Enabled **server-side encryption** to protect stored data.
5. Tested permissions by uploading and retrieving files with authorized accounts.

## Tools Used
- **AWS S3**
- **AWS IAM**
- **AWS CLI**

## Skills Demonstrated
- Cloud security best practices  
- Identity and access management  
- Data encryption and compliance awareness
